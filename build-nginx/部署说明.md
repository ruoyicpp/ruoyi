# RuoYi-Cpp 部署说明

## 快速启动（本地/局域网）

1. 启动程序
   ```
   ruoyi-cpp.exe
   ```
2. 浏览器访问
   ```
   http://localhost:18080
   ```

默认账号：`admin` / `admin123`

---

## 访问模式配置

编辑 `config.json` 中的 `listeners` 字段，选择以下任一模式：

### ① 本地 / 局域网（默认）

```json
"listeners": [
  { "address": "0.0.0.0", "port": 18080, "https": false }
]
```

访问地址：`http://localhost:18080` 或 `http://局域网IP:18080`

---

### ② 公网域名（HTTP，不带 HTTPS）

```json
"listeners": [
  { "address": "0.0.0.0", "port": 80, "https": false }
]
```

访问地址：`http://yourdomain.com`

**前提：**
- 域名 DNS A 记录 → 服务器公网 IP
- 防火墙放行 80 端口

---

### ③ 公网域名（HTTPS，绿色小锁）

#### 方式 A：手动上传证书（腾讯云/阿里云等购买的证书）

1. 从云服务商下载 **Nginx 格式**证书，得到 `.crt` 和 `.key` 两个文件
2. 将文件放到程序目录下的 `nginx/ssl/` 文件夹：
   ```
   nginx/ssl/server.crt   ← 证书文件
   nginx/ssl/server.key   ← 私钥文件
   ```
3. 修改 `config.json`，将 `listeners` 替换为（参考 `_listeners_https_example`）：
   ```json
   "listeners": [
     {
       "address": "0.0.0.0",
       "port": 80,
       "https": false,
       "_comment": "ACME HTTP-01 验证专用，证书申请成功后可关闭"
     },
     {
       "address": "0.0.0.0",
       "port": 18080,
       "https": true,
       "cert": "nginx/ssl/server.crt",
       "key": "nginx/ssl/server.key"
     }
   ]
   ```
4. 防火墙放行 80 和 18080 端口
5. 访问地址：`https://yourdomain.com:18080`

#### 方式 B：自动申请 Let's Encrypt 免费证书（ACME）

1. 修改 `config.json` 中 `acme` 块：
   ```json
   "acme": {
     "enabled": true,
     "domains": ["yourdomain.com"],
     "email": "你的邮箱@example.com",
     "acme_bin": "win-acme/wacs.exe"
   }
   ```
2. 将 `listeners` 改为方式 A 中的 HTTPS 配置
3. 确保 **端口 80 可被公网访问**（Let's Encrypt 验证需要）
4. 启动程序，自动申请证书并每 24 小时检查续签

## SSL 证书格式说明

从云服务商下载证书时，选以下任一格式均可：

| 格式 | 说明 |
|------|------|
| **Nginx** ✅ 推荐 | 直接使用 `.crt` + `.key` |
| **Apache** | 直接使用 `.crt` + `.key` |
| **其他** | 直接使用 `.crt` + `.key` |
| Tomcat / IIS | ❌ pfx/jks 格式，需转换，不推荐 |

---

## CORS 配置

如果前后端**分离部署**（前端和后端不同端口/域名），需要在 `cors.allow_origins` 中添加前端地址：

```json
"cors": {
  "allow_origins": [
    "https://yourdomain.com:18080",
    "http://localhost:3000"
  ]
}
```

如果前后端**统一部署**（后端直接托管前端 `./web` 目录），则无需修改 CORS，同源不跨域。

---

## 前端部署

将前端构建产物放到程序目录下的 `web/` 文件夹：

```
web/
  index.html
  static/
  ...
```

配置文件中对应项：
```json
"frontend": {
  "enabled": true,
  "dist_path": "./web",
  "api_prefix": "/prod-api"
}
```

## 常用端口

| 端口 | 说明 |
|------|------|
| 18080 | 默认 HTTP（本地开发） |
| 80 | 公网 HTTP / ACME 验证 |
| 443 | 公网 HTTPS（标准端口，无需带端口号访问） |
| 5432 | PostgreSQL 数据库 |
| 6379 | Redis |
